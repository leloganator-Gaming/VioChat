# Wolfanator

Jeu multijoueur de Loups-Garous en ligne.

## État du projet
- Nouvelle identité Wolfanator et interface d'accueil.
- Écran de village / lobby en cours de construction.
- Les parties en temps réel, les comptes, les salons et les rôles nécessitent encore le projet Supabase dédié.

## Configuration
Renseigner `supabaseUrl` et `supabasePublishableKey` dans `config.js` avec les valeurs du projet Wolfanator. Ne jamais utiliser une clé `service_role` ou `sb_secret` dans le navigateur.
